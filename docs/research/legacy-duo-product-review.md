## 1. What legacy Duo was

Legacy Duo (v0.1.0 2026-04-26 → v0.13.7 2026-09-20) was an Electron/Chromium macOS "agent-friendly IDE for product managers" (`docs/about-duo.md`): a three-column window — file navigator, tabbed terminal, and a polymorphic right "working pane" hosting browser tabs, a TipTap markdown editor, an editable HTML canvas, JSON/YAML, images and PDFs — with a `duo` CLI over a Unix socket as the agent's hands, so "nearly anything you can do in the app, Claude can do too" (`README.md`, `docs/duo-brief.md` §1, `docs/DECISIONS.md` § Layout model). It started as a browser-bridge for Google Docs (`docs/duo-brief.md` §2, §17) and grew, in five months of near-daily cuts, into: a document editor with CriticMarkup comments and track changes; HTML "pages/playgrounds/lessons" with click-to-agent actions and lesson/distro packs; a project rail (filter lens over open tabs); a Home re-entry screen with a Catch-up board of sessions; Obsidian/OKF "vaults" with rollup views; scheduled Claude sessions with an attention badge; git worktrees, clone, pull and an open-remote-doc → propose-PR flow; multi-window; file version history; and a fork/distro architecture for enterprise cohorts (`docs/roadmap.html`, `docs/RELEASES.md`). The persona was "the PM without a SWE background" (`docs/VISION.md`), but the shipped surface was engineer-shaped: git, worktrees, JSON editors, CDP, 80+ CLI verbs (`docs/prd/enh-253-repo-root-pull.md` §D: "81 verbs").

### 2.1 Locked stack decisions (`docs/duo-brief.md` §6, `docs/DECISIONS.md` § LOCKED)
