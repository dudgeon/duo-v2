Where your four ideas went

Architecture reviewThe code half of the fortnightly deep review (D). It looks at what changed since the last run, re-measures, and brings at most 5 proposals.
Feature intent documentA feature catalogue (C), written once and then updated by each feature merge. Docs stay current when they change with the code, not when an agent rewrites them.
Marketing and explainer videosA step in the release brief (B). Each feature gets a launch tier, Tier 1 features get a video proposal, and the release reports when the intro film is out of date.
Design-system maintainerSplit in two. The sync checks go in the weekly tidy-up (A). Pattern harvesting and refactor proposals are the design half of D, on a canvas.

What the last month showed

1,050 commits and 31 releases since 09-28. What drifted with no one noticing:

  • The design README still says chat mode is "not built". It was flagged on 10-12.
  • 38 stand-in questions are still open, the oldest for 24 days.
  • 130 Q rows read "open", and some already have their answer in the notes.
  • 19 in-progress task notes have no entry after 10-20, several for features that shipped in 0.2.18.
  • The README has no mention of a dozen features shipped from 0.2.18 to 0.2.20.
  • No performance budget run since 10-12, and the idle-CPU burn was found by accident.
  • There are 43 work trees.
  • Three Claude Code version breaks were found in the field.

What has a mechanical check barely drifted: duo2.md parity, the generated tokens, the video's --check. So the plan is a few jobs, and a check wherever a rule can be written down.

A separate doc-drift agent, or a separate Claude Code version watcherBoth are sections of the weekly tidy-up. Separate jobs would report the same things twice.
A flaky-test triage jobThere is one known flaky check (C-85) and none new this month. A merge-gate log covers it.
Auto-cleaning branches, work trees or sessionsOther teams found auto-closing bots do harm, and auto-cleaning would break the rule that sessions stay until you sign off. Jobs report; the director acts.
A standalone marketing agentIts input is a release, so it belongs in the release step.
Any daily job besides problem discoveryAt this pace a daily digest repeats itself, and repetition is what gets muted.
A job that edits code or messages workersSame rule as problem discovery: that would open a path for prompt injection.
