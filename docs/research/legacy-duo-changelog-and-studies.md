# Legacy Duo — what the changelog and research studies learned the hard way

Status: research · 2026-10-03 · Source: `~/repos/duo` (read-only) — `CHANGELOG.md` (2,299 lines, v0.1.0 → v0.13.7, 185 BUG / 201 ENH / 28 FOLLOWUP IDs, 33 stages) and `docs/research/` (≈60 studies) + `docs/legacy/faq.html`.

How to read this. Citations are `CL:NNN` = `~/repos/duo/CHANGELOG.md` line NNN, and `R:<file>` = `~/repos/duo/docs/research/<file>`. "Legacy" = the Electron/TipTap/xterm app. "v2" = the Swift/SwiftTerm/WKWebView/CM6 rewrite described in `docs/design/claude-design-handoff.md` and `docs/design/stack-recommendation.md`. Two other reviews cover the product docs and `core/`; this one only mines the changelog and the studies.

The one-paragraph version: the legacy app spent most of its 1,133 commits on four things — (1) keeping an editor buffer honest against a disk that Claude, git and iCloud also write to; (2) keeping a terminal alive and un-interfered-with while the Claude TUI owns it; (3) making a web view coexist with native chrome; and (4) giving the agent a precise, self-describing way to drive the app. Almost every "feature" study resolved to a small set of invariants (§2) that v2 can adopt by construction instead of by a year of BUG-xxx entries.

## 2. Hard-won invariants

Numbered so later docs can cite them as `LDI-n`.

**Files, state and truth**

1. **Files are the source of truth; never keep a sidecar that mirrors another system's state.** Sidecar comments were invisible to the agent and lost on move (BUG-138 CL:845–847); Home reads JSONL live with no cache (CL:324); a rollup registry `index.json` was rejected on principle (`R:vault-inbox-rollups-view.html` §4). The one sanctioned shape: a **rebuildable index refreshed on real evidence**, deletable at any time (ENH-231 digest materialized on the Stop hook; `R:async-catchup-home.html` "§D9 honest read"). v2's SQLite index must stay in this class.
2. **Capture on evidence, not speculation.** A fresh shell tab inherited a session id just by sharing a cwd (`R:bug-156-terminal-stability-postmortem.md` hyp. 3); cron pre-allocates its own `--session-id` rather than sniffing files afterwards (`R:enh-223-scheduled-sessions.html` D3).
3. **The conflict baseline is the raw bytes last seen on disk, never the editor's serialized view.** One ref doing double duty (dirty check + conflict check) produced every TipTap round-trip quirk as a false banner (BUG-166 CL:507; BUG-125 v2 CL:926; ENH-195 CL:425).
4. **On a clean buffer, any external byte change reloads byte-faithfully and is highlighted until the next keystroke; never silently swallowed.** >50% change ⇒ a one-line "reloaded from disk" note instead (CL:419, 425; `R:enh-195-cli-edits-disk-sync.html` D3).
5. **Echo-suppress your own writes by content registered *before* the write and cleared on the matching watcher event — not by a timer.** The 2 s TTL raced (BUG-099 CL:1424); bumped to 5 s (CL:973); still undershot on big files (ENH-195 A5). Hash the bytes, as the stack rec says.
6. **Never normalize untouched markdown on save.** Trailing newline (CL:1330), soft breaks (CL:808), `<!--` entities (CL:675), autolinks (CL:654, 663), tables (CL:287) each cost a release. The retired anti-pattern is "widen the compare regex" (`R:enh-195-cli-edits-disk-sync.html` "Locked decisions"). CM6 makes this structural; keep a save-path backstop that refuses a row-losing or length-collapsing serialize (CL:287).
7. **Reconciliation (watch → echo-vs-external → reload-or-banner) is one shared primitive across every file surface.** Per-surface mirroring "kept being missed" (CL:429; FOLLOWUP-019 CL:994). JSON, image and PDF viewers were silently stale until they joined it (CL:420).
8. **The agent edits an open file through the app, buffer-routed, and can ask "is this file open and dirty?"** Without a surgical verb and a status probe, Claude reached for raw `Edit` and clobbered buffers (`R:enh-195-cli-edits-disk-sync.html` "Why Claude reaches for the filesystem"; CL:416–418). Warn-only hook, never blocking (CL:422).
9. **Pause autosave while an agent-write decision is pending** (BUG-033 CL:1845), and keep the "Keep mine / Reload / View diff" banner for genuine divergence only (ENH-197/202 CL:398).
10. **Every save is snapshotted to content-addressed history with attribution (you / agent / restore); restore is safe because the current state is itself a snapshot** (ENH-221 CL:254; `R:enh-221-history-view.html`). Zero added save latency, 90 s autosave coalescing.
11. **Comments and tracked changes live inline in the markdown (CriticMarkup), with metadata pipe-delimited inside the token so any CM reader still sees the body; sidecars migrate silently on first load** (BUG-138 CL:845–847; `R:markdown-criticmarkup-comments-trackchanges.html` Q1/Q5).
12. **Suggesting mode must be transaction-level with an insertion/deletion exclusivity invariant: accept-all ⇒ new doc, reject-all ⇒ old doc, exactly.** Key-interception missed type-over/cut/paste/IME and corrupted the reject baseline (ENH-260 CL:34; `R:track-changes-composition.html` S1–S4).

**Terminal and the Claude TUI**

13. **Never resize a PTY to 0×0; guard at the lowest process-crossing boundary.** A `min-h-0` flex child transiently hit 0, `ioctl(TIOCSWINSZ)` wrote a degenerate size, Claude exited, SIGHUP took the shell (`R:bug-156-terminal-stability-postmortem.md`; `TERMINAL_MIN_COLS` CL:353). Audit every "measure DOM → write to backing system" loop (BUG-157).
14. **Hiding, collapsing or re-laying out a pane must never unmount or kill a terminal.** Collapse killed every session (BUG-200 CL:353). Keep PTY and buffer alive; stop drawing.
15. **Never inject keystrokes into a running Claude session on the user's behalf.** Auto-`/rename` was removed (CL:610, FOLLOWUP-028); paste strips the trailing newline (CL:1460); drag-drop inserts a quoted path with no newline (CL:362); `claude:spawn` passes the prompt as the first message (CL:1656); cron seeds via the positional prompt (`R:enh-223-scheduled-sessions.html` D2). Before writing to a fresh shell, wait for a real prompt (ANSI-stripped regex, not first byte: BUG-010 CL:2109).
16. **Don't fight the TUI's input semantics or try to style its input area from outside.** Return remap reverted (CL:1294) and the default flipped back (CL:966); Shift+Enter = newline is the one safe addition (CL:1247). The compose area is Claude's React tree; typography and reader-width are the only safe levers (`R:terminal-cozy-mode.md`).
17. **A terminal's project membership follows the live shell cwd, not its launch cwd.** Frozen cwd produced ghost tiles (BUG-191 CL:441); `⌘T` inherits the live cwd (ENH-187 CL:493); a deleted cwd falls back to the nearest surviving ancestor with an in-stream notice (BUG-165 CL:501).
18. **Resolve symlinks before encoding or comparing project paths** (`/tmp` → `/private/tmp`: BUG-158 CL:601; BUG-162 CL:557).

**Keyboard, chrome and web views**

19. **One typed global-shortcut registry, matched at capture phase; every embedded surface (terminal, web view, editor) forwards or consults it.** The alternative was the BUG-008/012/013/014 family (CL:2102, 2139). Avoid chords system tools pre-empt: `⌘\` (1Password), `⌘⌥L/;/'` (Raycast) (CL:1552, 1362). `⌘W` tab-only (CL:1726); `⌘R` never reloads the app (CL:1469); `⌘Z` yields to text undo inside any text surface (CL:261, 650).
20. **Native menus and native sheets wherever a web view can occlude DOM chrome.** z-index can't beat a native subview (BUG-006 CL:1722; BUG-047 "mute" workaround CL:1814 retired by ENH-050 CL:1591); the modal-occlusion class recurred in BUG-153, BUG-209, BUG-270 (CL:644, 266, 41) and shaped the worktree/history/vault designs toward sidebar DOM instead of centered modals (`R:worktree-lifecycle-ux.html` Option B rationale).
21. **Agent navigation never steals the user's tab or focus — but agent-created artifacts must be findable.** `duo navigate` focuses a matching tab or opens a new one, never replaces the active one (ENH-175 CL:648); cron lands in a background tab (CL:256); `--reveal` is an explicit opt-in that expands a collapsed pane (ENH-130 CL:1232). Send→agent must return OS focus to the terminal (ENH-236 CL:198).

**Sessions and attention**

22. **Agent-facing affordances gate on live agent presence, and that gate gets a regression test.** The pill showed with no destination four times (BUG-056 CL:1702, 1377; ENH-013 CL:1862). Presence = process-tree probe; precise state = hooks (ENH-225 CL:257) — in v2, `claude agents --json`.
23. **Attention has one axis: needs-you (act) · working (wait) · done (review).** Blocked is a reason chip under needs-you; plan-to-approve (`ExitPlanMode` with no approval) is the crispest needs-you signal; a closed session that needs you is never demoted to a one-liner (`R:async-catchup-board.html`).
24. **Pre-hydrate at rest, never infer at open.** Goal, last instruction, files, todos, state, artifacts are all deterministic from the transcript; only the narrative needs the agent, so the agent writes it (`sessions.note`/`next`) and the fallback is the last assistant block — never fabricate (`R:async-catchup-home.html` Pass 2).
25. **Open session ⇒ focus the existing terminal, never duplicate. Session running outside the app ⇒ fork (`--fork-session`) with a warning. Closed ⇒ resume in the current window, new terminal** (CL:324; `R:home-screen-study.html` D6).
26. **Done leads with "open session"; md/html deliverables lead with the artifact; PR/diff are secondary** (`R:async-catchup-board.html` "Done column").

**Projects and organisation**

27. **Projecthood is derived and never a front-door gate; deepest qualifying folder wins; `$HOME` and `/` never qualify; pinned tiles persist with zero members, unpinned ones auto-drop** (ENH-182 CL:565, 575; D1–D12 in `R:project-centric-ux.html`).
28. **Focus is a lens, not a switcher: it hides, never closes; releasing restores everything; opening something from another project switches focus; creating a terminal outside the focused project releases to All** (CL:565, 535, 365).
29. **Project colour is hash-stable from the root; the palette excludes the app accent; colour is never the only signal** (`R:project-rail-style-study.html`; override removed CL:385; orange reserved for Claude context `R:navigator-claude-context-worktree-pill.html`). Tile initials are word-aware and collision-free (CL:484).
30. **Stale references self-heal; a vanished folder yields a banner and a revert to a valid root, never a render crash.** Deleted-dir prune, cwd fallback, ghost-pin drop (CL:457–458), worktree removed under-foot (CL:255), per-pane error boundaries (CL:1476, 1620).

**Persistence, multi-window, distribution**

31. **Shared on-disk state has serialized writers, atomic temp+rename, a version field, a one-time `.bak` before migration, and older builds must degrade gracefully** (CL:403, 370, 376, 2025).
32. **Default resolution is by identity, never by focus** (lowest-id primary window; grep-gated: CL:366). App-global prefs fan out live to every window (CL:112, 171).
33. **Everything clickable has an agent twin, and the agent surface is the spec; a currency check keeps the four surfaces in sync** (ENH-203 CL:383; "CLI parity" on nearly every ENH). In v2 the twin is an MCP tool.
34. **Contradictory or missing guidance is a capability bug.** An agent built a bespoke dashboard because two docs disagreed (`R:okf-rollup-skill-proposal.html`); an agent burned 16 shell calls guessing an anchor shape (BUG-143 CL:722); a 600-line skill truncated its own hard rules (CL:1284). Hub + short spokes; per-tool help.
35. **Verify the artifact on disk before filing a fix from a verbal symptom** (BUG-159 CL:617; `customName` vs `customTitle` in `R:enh-183-step-0-empirics.md`; BUG-115 CL:1262).
36. **Assume enterprise Macs: no admin, no Homebrew, sandboxed Claude sessions, locked `~/.claude/settings.json`.** Fail open (BUG-117 CL:1160), put binaries where the PTY `PATH` already looks (CL:1050), TCP fallback (CL:2046), detect → validate → guide → run-with-consent (`R:integration-primitive-design.html`).
37. **Validate the packaged app launches before cutting; derive the version from one place; guard against stale binaries; unsigned builds can't auto-update** (CL:1960–1977, 402, 1136, 2035).
38. **Upgrades must migrate user-facing pointers and preserve user edits via provenance SHAs; only-if-absent bootstrap never reaches existing users** (CL:1006, 1167, 2004, 1893, 1001).
39. **Writers are idempotent and byte-equal when nothing changed** (no spurious watcher events or git churn: CL:311).
40. **Local-only browsing by default; off-host URLs open in the system browser with a visible "sent to your browser" banner** (CL:627, 2072).
41. **Polls are visibility-gated, filesystem walks are off the main thread, listings are stale-while-revalidate during agent bursts, big files degrade to read-only, and expensive reads are lazy for the visible top-N** (CL:441, 336, 305, 1193; `R:home-screen-study.html`).
42. **Both themes are first-class: tokens keyed off the real theme attribute, contrast checked in both, attention never colour-only, tab strips carry roles** (CL:265, 1551, 1813, 1242).

1. **CLI or MCP-only for agents?** The legacy "CLI is the spec" discipline produced ~100 verbs and a four-surface sync tax, but also let Claude drive the app from any shell and made `duo doctor` possible. v2 plans MCP tools. Do we also ship a thin `duo` binary (e.g. `duo open`, `duo doctor`) for humans and shell scripts, and if so is it a client of the same MCP server?
2. **Sandbox check for localhost HTTP MCP.** Legacy sessions in enterprise Claude sandboxes blocked Unix sockets and needed a TCP+token fallback (CL:2046). Spike 8 should confirm an HTTP MCP server on `127.0.0.1` is reachable from a sandboxed `claude` and from Remote-Control sessions.
3. **Track changes / comments: phase 2 or v1?** It is the most PM-shaped thing legacy built (reviewing Claude's edits in-window) and also the most expensive (BUG-138 → ENH-260 spanned ~5 months). Is "Ready for review shows Claude's additions marked" (brief prompt B.3) satisfied by the reload-highlight (req. 3) alone for v1?
4. **Digest cache posture.** Legacy chose "materialize on Stop hook" over "lazy at open". With `claude agents --json` giving state directly, do we still want a per-session digest file in `.duo/` (readable by the user, per brief §9) or keep it in the SQLite index only?
5. **"Ready for review" derivation.** Legacy had no such state; Done was "no live process + todos complete". Should v2 derive "ready for review" from (Stop + artifact written in project) or require the agent to call `sessions.next`/`note`? Both, with the deterministic one as fallback?
6. **Implicit projects.** Legacy qualified any git root / `CLAUDE.md` folder with activity. v2 has explicit `PROJECT.md`. Should folders Claude Code already has history for (`~/.claude/projects/*`) appear as "unregistered" projects to support "find before you create", and does Home/triage get to register them?
7. **Scope of Home re-entry vs. the left pane.** Legacy Home carried both re-entry (Projects mode: heroes, snippets, recent files) and Catch-up (attention board). In v2 the attention board is the left pane and Home is a project. Does the focused-project card absorb the Projects-mode content (last reply snippet, recent files, resumable sessions), or is there a separate "all projects" overview?
8. **Scheduled sessions in v1?** Legacy shipped them interactive-only late (v0.11.2). The Home/director pattern ("what Home did overnight", brief prompt D) implies scheduling. Defer to post-v1, or is a minimal "run this prompt at 7:40 in project X" in scope?
9. **Frontmatter editing model for tasks.** Legacy locked raw-YAML-only editing for the properties panel (CL:864 Q3=C) and only later built typed flips in the rollup viewer. For `tasks/*.md`, is the task row *the* editor (typed flips, undo toast) with raw YAML as the escape hatch?
10. **`TERM_PROGRAM`.** Legacy set `TERM_PROGRAM=Duo` on every PTY (CL:2177). The stack rec notes Claude Code only enables kitty keyboard protocol for allow-listed values. Decide whether to spoof an allow-listed value or accept the degraded key handling; test both in spike 1.
11. **Remote GitHub doc → "Propose changes".** Brief §1 says no PRs, but legacy built it specifically for PM docs that live in engineering repos (CL:258). Confirm it stays out of v1, or scope a read-only "open a GitHub doc" without the PR half.
12. **What Duo installs into `~/.claude`.** Legacy installed a skill, a subagent, hooks in `settings.json`, a managed block in `~/.claude/CLAUDE.md`, a PATH shim and a CLI, and spent many entries on upgrade/orphan/locked-file edge cases. Can v2 install *nothing* globally (per-session `--settings`, `--mcp-config`, `--append-system-prompt`) and only optionally sync a skill?
