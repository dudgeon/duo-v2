Actions on a chat turn: Copy, Rewind, Fork
Geoff, 2026-11-11: “in chat mode I want hover ui for rewind and fork; rewind has a button in claude desktop, but fork feels like a good fit too; … copy (which would copy the agent turn or user turn as raw markdown)”. Research: docs/research/chat-hover-actions.md. Every mark on boards 1 to 4 is a proposal [P]; nothing is built.
What Claude Code does (2.1.284 and 2.1.316, tried on a mock API)
Rewind is Claude's own menu (/rewind, or Esc Esc with an empty prompt): pick an earlier prompt, then Restore code and conversation · Restore conversation · Restore code · Summarize from here · Summarize up to here · Never mind.
Restore conversation removes that prompt and everything after it and puts the prompt back in the input. Same session, same file: the removed turns stay in the JSONL as a dead branch.
Restore code puts back what Claude’s Write and Edit changed from that turn on. Never Bash’s changes, never other apps’. 2.1.316 warns it loses “later changes by anyone”.
Fork: --resume X --fork-session --session-id N copies the whole session (Duo’s Resume as a Fork). Forking at an earlier turn has only a print-mode flag, so Duo forks whole, then rewinds the copy’s conversation.
The two versions differ only in words: 2.1.284 says “The conversation will be forked.”, 2.1.316 “This message and everything after it will be removed.”
What Duo has today
No per-turn actions. The code block’s Copy is the only button in the feed.
Chat keeps no transcript ids and follows file order, so after any rewind (even one typed in the terminal) it still shows the removed turns. Any build starts by keeping each turn’s uuid and following the live chain.
Claude desktop has Rewind and Fork from here on hover, a dry run listing files, and an Undo rewind (its bundle). Reports say Rewind there has no confirmation and gets clicked by accident.
claude.ai: Copy, Retry and thumbs under a reply; Edit on yours, which branches the chat.
The questions (recommendation first)
Q-505 · Which actions, where
A: a row on hover. Copy, Rewind, Fork on yours; Copy, Fork on Claude’s. B: Retry and Edit too. C: Copy now, the rest later.
Q-506 · What Rewind restores
A: Duo’s sheet asks, conversation only by default, code too when that turn changed files. B: conversation only. C: Claude’s whole menu.
Q-507 · How Duo rewinds
A: Duo drives Claude’s menu after its sheet, checking each screen. B: Duo opens Claude’s menu in the terminal for you.
Q-508 · Fork from a turn
A: fork, then rewind the copy; a new tab after this one, focused. B: the same, opened behind. C: only from the last reply.
Q-509 · What Copy copies
A: the words as Markdown, no thinking or tools. B: with one line per tool call. C: A, and ⌥-click for B.
