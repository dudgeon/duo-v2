A Duo question through SheetCenter (DuoQuestion), hung from the toolbar, never a system alert. Trust Folder is the default button (Return), Escape cancels. It is shown only after you press Trust This Folder…, or when duo2 asks (Q4).
Q1 A (recommended) · Duo writes the one key, after this
Trust “checkout” for Claude Code?
Claude Code trusts your Home folder, but stops at a git repository when /fork starts a background session. checkout became a repository after this session started, so it needs its own trust.
Duo will change one setting in Claude Code’s file, the one Claude sets when you answer “Yes, I trust this folder”:
Folder
/Users/you/claude-home/checkout
In ~/.claude.json
projects › …/checkout › hasTrustDialogAccepted: true
Only this folder. Claude Code will then use its settings, hooks and tools without asking, as it already does here in this session. Nothing else in the file changes.
The box shows the file and the one change, in mono: the path as Claude keys it (real path, the repository's top folder). If the session runs in a subfolder, the first line says "checkout (the repository's top folder, which holds api/)". With CLAUDE_CONFIG_DIR set, the box names that folder's .claude.json.
