>

"Couldn't change Claude Code's settings: ‹why›." Why: "another Claude is saving them; try again in a moment" (Claude's lock held past a few tries), "the file isn't readable as settings, so Duo left it alone" (not valid JSON), "Duo can't write to ~/.claude.json" (permissions). Try Again (default) and Not Now. Duo never writes a file it couldn't read whole, and never removes Claude's lock.
In chat the bar over the composer changes the same way: "Claude Code now trusts checkout." with Fork Again and OK; Fork Again sends your /fork line through the composer.
Not Now hides the bar for this session; the next "Workspace not trusted" brings it back. Nothing is remembered on disk.
Undo: none in the bar. Untrusting is Claude Code's own (its settings, or editing its file), as for any folder you trusted in Claude.
Logged: one line in Duo's log, "trusted ‹path› for Claude Code (asked by ‹you | duo2›)", so a trust Duo made can always be traced.
