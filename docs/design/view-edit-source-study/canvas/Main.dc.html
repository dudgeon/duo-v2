The caret or ⌥-click reveals one block’s source: frontmatter, a table, a comment, a slide marker. In HTML, an element’s source opens under it on the page. Whole-file Source Mode stays. Three weeks or more; the HTML half is a research risk.
Why A
  • It is what Geoff wants source for: checking exact Markdown, fixing HTML Claude wrote, seeing frontmatter and review marks as typed, copying exact text. Each is a whole-file, in-place, editable job.
  • Apps that render in place use a toggle (Obsidian, Typora); side by side belongs to editors whose text is plain (VS Code, iA Writer). ⌥⌘U is the Mac’s View Source (Safari, Chrome).
  • It costs the least. The HTML, CSS and JS parsers are already in the editor’s bundle (F-514: adding the HTML language grew it 5 bytes). Source Mode’s compartments exist; DL-77’s saving is language-blind.
  • It works at 360 with nothing to fold; the page beside its source stays one ⌥⌘P away, now highlighted.
