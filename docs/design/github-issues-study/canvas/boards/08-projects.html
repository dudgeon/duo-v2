8 · Later (ENH-68): a GitHub Project as the board’s source
The board header’s TASKS · n becomes a source popup when the repo’s owner has Projects linked to it. A Project shows in the same board: its column field’s options (Status by default) are the lanes, in GitHub’s order, with No Status first; items are cards with the issue mark; a drag writes the field with gh project item-edit; ⌘Z writes it back. Sessions attach through the local task that tracks the item’s issue. Columns are edited on GitHub (no + Add Column). [P]

Why later
