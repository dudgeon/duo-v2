DECISION 6 A session open in two windows Window 1 shows Refund rules' terminal. You open refunds in window 2 too. Its process is shared, but its terminal can be drawn in only one window. Chat mode can be drawn anywhere, and it types into the same session.
A · Chat here, the terminal stays thererecommended
The second window shows the session in chat mode: read it, answer it, approve from it. Show Terminal Here moves the terminal over, and window 1 turns to chat. Nothing is ever blank.
B · A stand-in, Show Here
As iTerm2 does: the console says where it is and moves it on a click. Simple and honest, but the pane is empty until you click.
C · Its window comes forward instead
Clicking a session that's live elsewhere jumps to window 1, as Xcode does with an open project. Never two copies, but window 2 can't show refunds at all while window 1 does.
