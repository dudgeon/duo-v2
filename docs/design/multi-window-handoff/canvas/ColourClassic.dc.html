DECISION 4c · ENH-319 · Q-435 · DL-252 Window colours and Classic, never both [P] Geoff: “would need to be mutually exclusive w classic mode”. Classic (DL-252) is a whole-app Appearance: paper grounds, its own console and red needs-you, light only. A base colour repaints the same grounds, so the two can't be on together. The question is which one gives way.
A · Classic turns window colours off [P]recommended
GENERAL
AppearanceClassic⌃ Window colours are off while Classic is on. Each window gets its own back when you choose another appearance. [P]
Choosing Classic is one deliberate choice for the whole app, so it wins: every window goes Classic and the swatch leaves the toolbar. Window › Window Colour stays in the menu, dimmed, with the same line. Nothing is forgotten: Sky comes back when you leave Classic. Windows are still told apart by their title and the Window menu.
B · Window colours make Classic unavailable [P]
GENERAL
Appearance ✓ Match System Light Dark Classic Classic isn't available while a window has a colour. Set every window to None to use it. [P]
Colours win and Classic is dimmed until no window has one. With Colour new windows automatically on, that is as soon as you open a second window, so Classic would mostly be out of reach for anyone who uses windows.
