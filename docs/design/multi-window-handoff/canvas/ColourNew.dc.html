DECISION 4b · ENH-319 · Q-435 A new window's colour, and how you change it [P] Geoff: “we could even have each new window automatically pop in a new color”. The window you have today stays None unless you colour it. Changing a colour is the same in every option: the swatch after the project's name, Window › Window Colour, or duo2 window colour <name>.
A · Each new window takes the next colour [P]recommended
New Window ⌥⌘N gives the window the first colour no open window has, in the order Sky, Sage, Lilac, Sand, then round again. Your first window keeps None, so Duo looks as it does today until you open a second. A window keeps its colour through relaunch. A switch in the swatch's menu turns this off.

The swatch sits after the project's name, in the colour's swatch shade; a click opens the five colours and the switch. Window › Window Colour has the same five, with a check on the window's own. Only the key window changes.
B · New windows open plain; you pick [P]
Every window opens as Duo looks today, with an empty swatch after the project's name. Nothing changes unless you ask, but two windows look the same until you do, which is what the colours are for.
