Select several sessions, then act on all of them

Geoff, 2026-10-29: “shift click a range of sessions (without them opening if parked), control click in that range, and delete them.” Finder's and Mail's rules, on Duo's session rows. Everything here is [P].

The clicks
Click
What it does
On a parked session
Click
Opens the session in the console, as today, and clears any selection. It becomes the anchor.
Resumes it, as today (DL-156).
⇧-click
Selects every session row from the anchor to this one, in the order on screen. Task lines, fold rows and section labels in between aren't selected; folded rows aren't either. Replaces the last ⇧ range, as Finder does.
Selects it. Never resumes, never opens a tab.
⌘-click
Adds the row to the selection, or takes it out. It becomes the anchor for the next ⇧-click.
Selects it. Never resumes.
⌃-click, right-click
On a selected row: the menu for the whole selection (board 02). On a row outside it: the selection moves to that row, and its own menu opens, as in Finder.
Never resumes.
Esc
Clears the selection, while the list has the keyboard.
—
Click on empty pane
Clears the selection.
—
⌘A
While the list has the keyboard (after a click in it, or ⌥⌘← to its pane): every session row showing in that list. Not task lines, not folded rows. In a terminal, ⌘A stays the terminal's.
Selects; never resumes.
“Control click” (Q-a)
  • On a Mac, ⌃-click is right-click: it opens a menu. So ⌘-click adds or removes one row, as everywhere else on the Mac.
  • ⌃-click inside the selection opens the selection's menu, so “control click in that range, then Delete” works as Geoff said it.
  • Q-a asks Geoff which he meant.
What a selection is
  • Sessions only, across sections: NEEDS YOU, OPEN, a task's rows and OTHER SESSIONS can be selected together.
  • One list at a time. Switching project or altitude clears it.
  • A selected session that changes section (it starts working, it needs you) stays selected. The list already holds still while the pointer is in it (DL-130).
  • A session that leaves the list (archived, deleted, moved) leaves the selection.
  • The console keeps showing what it showed. Selecting never changes the console.
After the action
  • Archive, Park, Add to Task and Move to Project act at once, with ⌘Z, as they do for one session.
  • Delete asks once, in a sheet (board 03): it can't be undone.
  • The selection clears after any action.
  • VoiceOver: “3 sessions selected”; each row reads “selected”.
