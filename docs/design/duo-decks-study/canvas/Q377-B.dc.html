B · Add templates from the pack You start where the templates live. The pack's note gets a bar with Add from a Deck… and Specimen. A sheet picks a deck in the project and ticks slides in a thumbnail grid. A new pack starts from File › New › Template Pack…, which opens the same sheet.
  • The pack is chosen first, so "which pack?" never needs asking.
  • One home for pack work: add, specimen, rebuild.
  • Verbs: duo2 deck template add <pack> <pptx> --slides 3,7.
Against: you must think "pack" before "this slide". Slides are small in a sheet, and the deck you were looking at is behind it. The first pack needs a separate New Template Pack… entry.
