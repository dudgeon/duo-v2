What acts on what, in a split (option C)
One rule: the active side is model state, set when you click or type in a side, and every command reads it. Legacy guessed it from DOM focus and never got it right (ENH-084). [P]
CommandIn a split
⌘WCloses the active side; the other becomes an ordinary tab. Never the console’s session (F-479: today ⌘W from a page or deck may end it).
⌘SSaves the active side’s document; on a preview side, its source.
⌘FFinds in the active side (the responder chain already routes it).
⌘DSends the active side’s selection to Claude; on a deck preview, the picked shape and its slot (Duo Decks R4).
⇧⌘D voiceInto the active editor; with a preview active, into its source (R8).
Formatting barOver the editor side only, while it has the keyboard (DL-266 unchanged); never over a preview.
Review barIn each editor side’s own stack.
⌃Tab / ⌃⇧TabThe right pane’s tabs; the split is one tab.
⌥⌘← / →Sidebar → console → left side → right side, wrapping (Q-368). The rule moves with it.
⌥⌘P [P]Preview Beside / Close Preview for the showing file (a new chord, DL-34; Q-364). Checked against 1Password, Raycast, Rectangle and macOS defaults before it’s logged (BUG-075).
⌥⌘↩Search’s “Open in split view” (DL-79 e, already approved): the result goes beside the showing tab.
duo2 verbs (DL-71)
Every control names one. Agents split only when asked: duo2 open never splits (legacy SV-12).
VerbDoes
duo2 split <file>The file beside its preview (deck, Markdown, HTML)
duo2 split <file> --beside <file|url>Two items side by side (slice 2)
duo2 splitState: sides, active side, ratio, folded, sidebar folded by the split
duo2 split close [--side left|right]Close a side, or the split; nothing is lost
duo2 split focus left|rightMake a side active
duo2 split swap · separateSwap Sides · Separate into two tabs
duo2 split ratio <0.2–0.8>The divider; clamped so neither side goes under 340
doc read, doc screenshot, slide …, statusGain --side; with none, the active side
duo2 deck …, deck go <n>, deck pickDuo Decks’ own; deck go moves both sides
Persistence (Duo Decks R10) Each split tab is saved in the restore file with its sides, ratio, active side and whether it’s folded (not in the project, so Obsidian and OKF never see it). A file opened in split reopens in split, its divider where it was left.
