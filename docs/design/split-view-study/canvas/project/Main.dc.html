What legacy taught (legacy.md)
  • The active side was never modelled. ⌘W, the focus glow and the agent’s “current document” ignored the split; three fixes failed (ENH-084).
  • A second native web view painted over the page. Nine bugs, BUG-092 to BUG-270.
  • One file could end up in two editors, each reading the other’s saves as outside changes.
  • ⌘\ was taken by 1Password (BUG-075). No narrow rules. Unit tests only.
  • Source beside its preview (“Option D, linked twin views”) was deferred and never built. That is the deck case.
