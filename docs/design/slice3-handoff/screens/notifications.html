The rules [P]
Only needs you notifies. Ready for review and working never do.
One per wait: a session that keeps waiting doesn’t repeat. Never for the session you’re looking at, and never while Duo is in front.
The title is the session, the subtitle its project and reason, the text Claude’s question as asked. Clicking it opens the project with the card selected.
macOS asks for permission the first time a session needs you while Duo is in the background, never at launch and never in a scripted run.
The Dock badge counts sessions that need you; none, no badge. Both can be turned off in Settings.
