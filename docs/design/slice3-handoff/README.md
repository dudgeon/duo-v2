# Duo slice 3: what v1 still needs — design handoff

Status: approved, 2026-10-05 (DL-101, DL-102: "Slice 3 looks good", build as drawn) · Owner: Geoff · Answers `docs/design/design-brief-slice-3.md`. Designed by Claude in the build session, on the canvas https://claude.ai/artifact/GNXvk4CWjarrXeURrLcyVY with the Duo design system.

Same shape and rule as `slice2-handoff/`: the files in `screens/` are the target (`screens/manifest.json` lists them). Everything macOS draws (notifications, the Dock badge, menus, the date picker) is exempt; the boards show only their content.

## What the screens settle

- **S3-1 · Settings** (`settings`, `settings-states`; DB-10, Q-12). A native Settings window (⌘,), one pane on `ground`, groups under section labels, each a `pane` box with `rule` border and radius 6; rows: a 150-wide label, the value (paths in `mono`) with a `text2` line under it, buttons on the right. Groups: Claude Code (path, version, Choose…), Home (folder, Change…, Show in Finder), Sessions (the archive's size, Show in Finder; no limit, DL-56), Notifications (two checkboxes, S3-6), Claude outside Duo (duo2 everywhere: Remove…/Install…; Legacy Duo: Restore/Disable…), Browser (allowed sites, Edit…). States: Claude Code not found; a chosen path that doesn't run (Use Found One); not installed; legacy found.
- **S3-2 · A folder moved or missing** (`missing-folder`; DB-8). The tile stays, says what happened in `text`, the old path in `text2`, then its buttons: not found (Locate Folder…, Remove from Duo); found elsewhere (Use New Place as the default button, Locate Folder…); in the Trash (Put Back, Remove from Duo); on a disk that isn't connected (no buttons). Inside the project, a notice on `ground`, radius 6, padding 8 12, over the session list; FILES says "Folder not found".
- **S3-3 · Launch questions** (`launch-questions`; DB-11, DL-39, DL-75, DL-50). Duo's own sheets, hung from the toolbar like Move into Home, one at a time: legacy Duo (what it found, each with its path, in a `pane` box; Not Now, Disable), install consent (Not Now, Install), `.gitignore` (Don't Add, Add to .gitignore), and a partly failed disable (Show in Finder, OK).
- **S3-4 · Editor notices** (`editor-notices`; DB-14, DL-77). A bar under the tabs on `ground` with a `rule` below, padding 10 20, the message, a `text2` line, the buttons (default as on sheets). A conflict also outlines its lines in the text, 1.5 `text`, labelled "Lines 14–16 · changed on disk". A rename Duo saw: the tab follows and the bar says so (OK). Read only says why. A notice on a tab you aren't looking at: "· conflict" after the tab's name.
- **S3-5 · How documents are drawn** (`editor-document`, `editor-states`; DB-15). H1 18/24 semibold, H2 14/20 semibold, H3 13/20 semibold; list marks hang in `text2`; task boxes drawn (12, radius 3; done: filled `text` with a white check, the text in `text2`); quotes with a 2 `controlEdge` bar and `text2`; code blocks on `ground`, radius 6, padding 8 12, mono 12/19, the language top right in 11 `text2`; inline code mono 12; tables with `rule` borders, header on `ground`, wide ones scroll in their box; images radius 6 with a `rule` border and a 12 `text2` caption; a missing image is a dashed `controlEdge` box naming the file. Claude's deletions: a hairline marker, "2 lines removed by Claude · Show · Revert", cleared with the highlight (DL-5). Find in Duo's look.
- **S3-6 · Notifications and the Dock badge** (`notifications`; DB-27). Needs you only; one per wait; never for the session you're looking at, never while Duo is in front. Title: the session; subtitle: project · reason; text: the question. Clicking opens the project with the card selected. Permission is asked the first time it would notify, never at launch or in a scripted run. Dock badge = sessions needing you. Both switchable in Settings.
- **S3-7 · Confirmations** (`confirmations`; DB-12, DB-36). Merge, Delete Session… and Make a Project as Duo's sheets in the S2 shape, listing what moves; Delete says it can't be undone.
