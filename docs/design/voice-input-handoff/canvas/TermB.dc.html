Duo only ever erases characters it typed itself since the last settled phrase. If you type or move the cursor, Duo stops correcting and finishes the dictation.

Trade-offs
  • For: words appear as you say them, the most direct feel; nothing added to the strip or drawn over the TUI.
  • Against: text in Claude’s prompt jumps and rewrites itself, and provisional words look final; every correction is backspaces into a live TUI, so if Claude Code redraws, wraps a long line or moves its cursor (a slash menu opening, a paste-collapsed “[Pasted text]” block) Duo can erase the wrong characters. Claude Code collapses long pastes, so typed text would have to go as keystrokes, where / and @ at a word’s start open Claude’s menus. More to test on each Claude Code version (2.1.219, 2.1.284, latest).
