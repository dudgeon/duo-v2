On the console strip as DL-253 draws it: the Terminal / Chat toggle on the selected tab, + and robot | shell at the end. Voice input adds no button there. ⇧⌘D or Edit › Start Voice Input starts it; while Duo listens, the selected tab’s state glyph becomes a small level meter. Trade-offs
  • For: the words land in Claude’s own prompt, the composer of the terminal, as you speak; nothing new in the strip; nothing drawn over the TUI; a paste is all it needs, so it works on 2.1.219 and 2.1.284.
  • Against: the words come a phrase at a time (1–2 s behind your voice), not word by word; no visible button in the terminal, only the chord and the Edit menu (chat has the visible mic); typing in Claude’s prompt while dictating finishes the dictation first.
  • Shell tabs: the same, into the shell’s prompt. Return is never pressed there either.
