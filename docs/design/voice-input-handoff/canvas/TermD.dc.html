D · Claude Code’s own voice mode (/voice), with Duo only turning it on [P, not recommended]

Claude Code has had hold-to-talk dictation since early 2026 (/voice; the voice:pushToTalk key is in the 2.1.71 changelog, voice.enabled in 2.1.239), so 2.1.284 has it. It transcribes in Anthropic’s cloud, not on the Mac, so it misses Geoff’s brief: “leverage the on-device transcription service”.

Drawn from its strings, not a capture (dashed: stand-in). Claude Code shows live partial text in its input with a waveform cursor. Duo draws nothing: no button, no bar. Hold mode never sends unless voice.autoSubmit is on (off by default). Tap mode (“tap to start, tap again to send”) sends on the second tap.

2 · Duo’s part · one setting, written for Duo’s sessions
Claude Code’s voice mode in Duo’s sessions
Hold Space in Claude’s prompt to talk. Uses your claude.ai sign-in; Anthropic transcribes it.

Duo would pass voice.enabled through --settings when it starts a session, never writing the user’s ~/.claude/settings.json. The mic button can’t drive it: a terminal sends no key-up, so Claude Code detects a held Space from key repeat, which Duo can’t fake from a click, and tap mode presses send.

Trade-offs
  • For: almost no Duo work; Claude Code’s own partials, in its own input, maintained by Anthropic; the TUI is untouched; probably more accurate on jargon than Apple’s model.
  • Against: audio goes to Anthropic, which breaks the on-device brief and the promise that nothing leaves the Mac; claude.ai login only (hidden for other sign-ins, and an organisation policy can turn it off: likely on the work Mac); needs SoX or Claude’s native audio; macOS likely charges the microphone to Duo as the host app, so Duo still needs the entitlement and usage string, with a prompt Duo didn’t explain (to check); no help for chat, which needs Duo’s own mic anyway; two different dictation systems in one app.
  • Could still coexist: nothing stops a user turning /voice on themselves today. If Duo ships A, both work; Space belongs to Claude Code and ⇧⌘D to Duo.
