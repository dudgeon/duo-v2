Where chat has its mic. Claude Code draws this box, not Duo, so Duo lays the mic over the right end of the box’s bottom rule, 2 columns in from the corner, on a console patch that breaks the line. That row never holds typed text, so nothing you type is covered. Needs a DL: the one exception to “Duo draws nothing inside the terminal”.

Recommendation
  • C3, in Claude’s input box, matches chat: the mic is in the composer either way. Its cost is the exception to the terminal rule and tracking the box on 2.1.219, 2.1.284 and latest, which chat’s screen reader already does.
  • C2, the footer, keeps the rule whole and needs no screen reading, at a 30 row. C1 is the cheapest and the easiest to miss.
  • Shell tabs: the same mic, words into the shell’s prompt. Return is never pressed.
