WHAT DUO DOES WHEN IT MAKES THE FILE
1. Picks the template: the project's templates/, then Home's, then this base.
2. Fills {{title}}, {{date}}, {{time}}, {{date:YYYY-MM-DD}}; leaves <% … %> as written.
3. Sets the keys it knows (goal, status, sessions) by name, touching nothing else.
4. Never writes over a file that's there.
