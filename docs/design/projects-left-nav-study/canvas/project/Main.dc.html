Where projects live in the window, and which project you are in

Q-515 (DL-339): a canvas round first. Two new users could not tell which project they were in or what a project is (ENH-146, 2026-10-14; F-663, 2026-11-12). Every new mark on these boards is a proposal, [P]. Sample data is the home-evolution study's. Nothing here is built.

What they said

“When I go to all projects, I would have expected to see a add new project and a listing in the left nav of my projects which I could expand (as I can in CC or ChatGPT) then I can start new sessions in my projects.”

First new user, ENH-146

New Session assumes a project, “but which one, how is a project defined, and where can I see that?”

Second new user, F-663 (aram-feedback §1.6)

What's true today

  • A project is a folder with a _PROJECT.md; a session belongs to the nearest one at or above where it started. The app says neither.
  • All projects has no left pane since DL-336; its sidebar button is hidden there.
  • Inside a project, the folder shows once, as an unlabelled grey line under FILES; the sidebar's “+ New Claude Code session” doesn't say where it starts.
  • The Board is a map of projects, but you can't start a session from a tile in one step, and it's gone once you're in a project.
