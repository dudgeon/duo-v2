12 · ⇧⌘N makes a note in the inbox and opens it in the editor (DL-152)
Geoff: “this should be a new note in the existing right pane markdown editor, not some new modal”, on ⇧⌘N, in Duo only for now. New Note in Inbox ⇧⌘N (File menu and the right pane’s +; there only once a knowledge base exists) makes <inbox>/YYYY-MM-DD-HHmm.md (-2 on a collision; a time-stamped name, as Obsidian’s Unique note creator makes) from templates/new-note.md through the templates engine, and opens it in the right pane with the cursor on its heading. The inbox is the knowledge base you’re in, else the default one. Typing is saved as you go; Esc or ⌘W on a note still empty deletes it. New Folder moves to ⌥⇧⌘N (legacy Duo’s mapping). The file name never changes after (format doc §4.5); the heading is the title. Duo’s base template is two keys: type: note (OKF’s one required key) and created (a date, as DL-146 and Web Clipper write it). duo2 note new [--kb <p>] [--stdin].
