WHAT IT DOES
Creates. A Claude session in the chosen project's folder, in the mode that project's sessions open in (Home: chat). Home: it opens in Home's pane and takes the top of OPEN, selected. A project: Duo jumps in with the new tab selected, as a row click does (DL-142 (5)). The popup lists ★ home, your projects by last activity, then New Project…; it remembers the last pick (Home at first). No shell here: shells aren't rows in this list, and ⇧⌘T already opens one in Home.
Keys. ⌘T at All projects = this row with its current pick (F-446's fix). The row takes focus with Tab like any control; Return presses it.
duo2. duo2 session new --project <p>; with no --project at All projects it uses the row's pick. The popup is that argument, so no new verb.
Sizes. 28 high, 16 in, 8 below, like the needs-you line under it; 1 pt dashed controlEdge, radius 6. Robot 12 × 8 in text2; popup 20 high, rule border. Hover selected, pressed menuTarget, robot to text.
For. Says where before you click; starts in any project without leaving All projects first; visible at rest and with the left pane hidden.
Against. 36 pt of the list's height; a new control (the popup); the robot without its shell half.
