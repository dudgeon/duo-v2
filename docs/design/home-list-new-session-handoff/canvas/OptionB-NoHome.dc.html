Geoff: “what is populated in the dropdown if no home folder is selected? what is a safe default?” Home is optional (DL-82). With no Home, B has no default: the popup says Choose… and opens on the row's click or ⌘T, so Claude never starts somewhere you didn't pick.

THE RULES
When there's no Home. Before you choose one (first launch, or Not Now), and when the chosen folder is moved or deleted: the scan finds no _HOME.md there, and Home's pane says “Choose a Home folder”. Every session is still listed (DL-82). The work Mac follows the same code.
The popup lists ★ home when there is one; then the projects Duo knows (in Home, made in Duo, or a folder with a _PROJECT.md that Claude ran in), by last activity; then New Project… and, with no Home, Choose Home Folder…. Plain folders aren't listed: make one a project first.
The default: your last pick if it's still there; else Home; else none. With none the row reads Choose…, and the row and ⌘T open the popup instead of starting anything. Never ~, never a folder you didn't pick, and never silently another project.
Trust. Whatever is picked, the start goes through the same trust check as every new session (DL-229; the trust-before-start sheet chat-reliability is building). An untrusted folder asks first, and nothing starts until you say yes.
