WHAT ~/DOCUMENTS MEANS (2.1.311 AND 2.1.284)
Trust is saved. Claude's home-folder rule is an exact match on ~, so ~/Documents asks once and remembers, like any folder. Each start still goes through the trust check.
macOS asks once, for Duo. Documents is a protected folder. The first time Duo starts Claude there or lists its files, macOS asks “Duo” would like to access files in your Documents folder (Duo spawns Claude, so the prompt is in Duo's name). Until it's answered, reads there wait (F-28). A managed Mac's profile may grant or block it.
iCloud. With Desktop & Documents in iCloud, ~/Documents is still the path, but files may be cloud-only, so Claude's reads download them or fail offline (not tested). On this Mac it's a local folder and iCloud Drive keeps a separate Documents folder.
Missing. No ~/Documents: no default. The row reads Choose… and opens the popup. Duo never makes the folder and never falls back to ~.
Where it shows. A folder row, ~/Documents, which Duo's inventory already counts as a catch-all folder (FR-7.2.8).
