Editing and saving [P]

· Source is the ordinary editor with the HTML language: typing, undo, find, ⌘D to Claude. It autosaves 1 s after typing and merges with the disk before writing (DL-77); a real overlap with Claude’s rewrite shows today’s conflict bar, Keep Mine / Use Theirs (C-142).

· The Markdown-only parts stay off: the properties block, tables, lists, review marks, title-follows-heading.

Keeping your place [P]

· Page → Source: the editor scrolls to the tag of the element at the top of the viewport (elements matched to the parse tree in document order).

· Source → Page: the page reloads from the buffer, so unsaved text shows, and scrolls to the element whose tag holds the caret.

· While Source shows, the viewer doesn’t reload from disk; Claude’s changes arrive in the editor as for Markdown.

Copying: from Source, exact text; from Page, as today.
