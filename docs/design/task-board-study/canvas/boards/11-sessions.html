One strip: the session mark, every session’s glyph, “3 sessions”, a chevron. A click opens a popover listing them; a second click opens one. Tidiest, but two clicks.

A click on a session [P]

  • Opens it. The board switches to Sessions with that session selected and its tab in front, resumed if it was closed (as a session link does, DL-87). The task’s note stays in the right pane.
  • Right-click: the session menu (DL-108), so Remove from “task” is there (CX study board 12).
  • A click anywhere else on the card selects it and opens its note on the right.
  • The + on hover is still New Session in Task (DL-112).

Why S1 (approved, DL-148)

It answers both parts of the note: the mark and the label say “session”, and a filled row with a hover arrow says “click to open”. Cards get taller (22 per session, at most 3 rows), which C’s 980 has room for.

Same rows elsewhere

The task note’s properties already list sessions (DL-102). S1 gives the card the same order and glyphs, so a session looks the same on the card and in the note.
