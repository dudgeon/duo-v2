Why

  • One truth. status in each note is the lane, in Duo, in Bases, in TaskNotes. Nothing to sync, nothing to drift, no new key.
  • Obsidian caught up this week. Bases Kanban (1.14.4, public 2026-10-05) is the same model, so “the same board in Obsidian” is one generated file, not a plugin dependency.
  • C fits planning: the board and the task’s note side by side at 1440 and 1280, no reflow.
  • Computed order matches what Bases can do and keeps files quiet.
