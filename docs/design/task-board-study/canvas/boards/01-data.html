Why not (b)

The Kanban plugin keeps lanes in a note of its own. A task’s lane would live in two places (the board note and the task’s status), and the plugin rewrites the whole note on every change, so Duo couldn’t edit it surgically. It also can’t read one-note-per-task boards, which is Duo’s format (DL-6). It stays readable: a card that links a task note is just a link.

Statuses Duo doesn’t know

Someone types status: blocked in Obsidian. Duo shows a blocked lane at the end, in text2, and never rewrites the value. In Obsidian, a base whose groupOrder lists Duo’s five hides it (Bases shows only listed groups), so the tasks.base Duo writes leaves groupOrder to the user after the first write [P, Q-121].
