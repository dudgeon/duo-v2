2 · The branch: a new branch for this work, or one that’s already there
A new branch is the default, named <your GitHub login>/<project slug> (or <slug> without gh), made from the repo’s default branch. It exists only on this Mac until the first push, so making a project never changes GitHub. Picking an existing branch is for joining someone’s work: reviewing a colleague’s PR or picking up your own branch on another Mac. [P]

Rules [P]

  • A new branch’s name is checked as typed (git check-ref-format), and must not start with “-”. Taken on GitHub: “That name is taken on GitHub. Pick it under ‘A branch that’s already there’, or change the name.”
  • No branch picker after the project is made: one project, one branch. Another branch of the same repo is another project (board 3).
