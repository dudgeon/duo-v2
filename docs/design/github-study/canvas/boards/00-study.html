What changes from the legacy call

legacy-requirements.md dropped “Git for PMs: worktrees UI, clone, pull, propose-changes PR, repo chips” from v1 as code-shaped. This study brings back four of the five, reshaped: getting a repo (as a new project), its state on the project, Push / Open PR (with the fork path), and Get Latest. The worktrees UI stays out. Kept from the call: the vanished-folder recovery and fail-closed probes.

Principles [P]

  • Duo does the mechanics, Claude does the words. Duo runs the network and permission steps the same way every time and explains their failures; Claude writes commit messages and PR descriptions and resolves conflicts, from an instruction Duo drafts.
  • Never a token. Duo uses the user’s own gh auth or git’s credential helper (the macOS keychain). It never asks for, stores or reads a token.
  • Works without gh. Paste a link, push with git, and open the pull request on GitHub’s own page. gh adds the repo picker, the fork path and PRs opened from Duo.
  • Assume no admin, maybe no write. A project from GitHub starts on its own branch, so a protected main never blocks it; no write access means a fork, said plainly before it happens.
  • Not a git client. No staging area, history graph, rebase or branch manager. One branch per project, set when it’s made.
  • Every action has a duo2 repo verb (DL-71). Nothing here shows a system alert.

Legacy Duo, in short (docs/research/github-primitives.md §1)

  • Repo chips (branch, ahead/behind, modified): Geoff called v1 “very bad” for hiding when clean; took five rounds. Kept as an idea, redrawn.
  • Clone from File, the tree and ⌘O; gh repo clone with a git clone fallback; raw stderr on failure.
  • Pull: fetch, fast-forward or merge, abort on conflict; a red “Discard my changes and pull”. Shipped with no live walk.
  • Propose changes: commit, push, auto-fork when not WRITE, gh pr create. Worked end to end; failures were raw stderr; forked even when the probe failed.
  • Worktrees UI: Geoff’s favourite, but its sessions broke when a worktree was removed.

What others do (§2)

  • GitHub Desktop: one button that becomes Publish, Push, Pull or Fetch; asks before forking (“contribute to the parent” or “for my own purposes”).
  • VS Code: Sync Changes; offers to fork when a push is refused.
  • gh pr create offers to fork when you can’t push; gh repo fork renames your origin to upstream unless told not to.
  • Claude Code already commits and runs gh pr create when asked; it doesn’t know your permissions until a push fails.
  • GitHub’s web editor forks for you when you edit a repo you can’t write to: “Propose changes”.
