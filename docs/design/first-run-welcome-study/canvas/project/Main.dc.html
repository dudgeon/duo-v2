A · A welcome sheet
One Duo sheet at first launch: the intro film's poster, three short panels (sessions in chat or terminal; projects and tasks; a director, when you want one), Start Using Duo. Help › Welcome to Duo shows it again.Said once, before any use; read or skipped, then gone. Queues with the install question.Board A1
B · Getting started with Duo · recommended
A card at the top of All projects: three optional steps that tick on the real action (open or make a project; start a session, chat or terminal; make a task), each with Show me, which opens that explainer on the real control. The director is a line to know about, with its film: never a step.Learn by doing; nothing modal; the same pattern DL-147 chose for a new project's card. Hide, or Help › Getting Started.Boards B1, B2, B3
C · Explainers that open themselves
No welcome. The first time a new user meets the pill, a project, Home or a task, that explainer opens once by itself; after a few sessions in one project, a quiet line in the sidebar says a director could run them.Least new surface; but popovers that open by themselves interrupt, and DL-172 kept explainers to a long hover.Boards C1, C2
