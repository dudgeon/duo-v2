Spec [P]

Where. Under the tabs on every Markdown document (not templates' preview or read-only files, where it hides), below the review bar when that shows. 32 high (new formatBarHeight), on pane, a rule below. It comes with its view, so no slide. View › Hide Formatting Bar turns it off everywhere.

Controls. Glyphs 28 × 24, radius 6, in text2. Under the pointer, and when on at the caret, a selected fill with the glyph in text; never the accent. Tooltips give the menu name and chord (Bold ⌘B, Italic ⌘I, Link ⌘K). Style ⌄: Body, Heading 1–3, Quote, Bulleted List, Numbered List, Task, Code Block. ⋯: Strikethrough ⇧⌘X, Code. Clicks never take focus from the text.

In a table. + Row, + Column, Align ⌄, Delete ⌄ take Style's place, the same commands as Format › Table. The in-document bar goes: amends DL-113 and DL-182.

Mic. At the trailing end, 24 round: rest, selected under the pointer, text fill listening, mic.slash with no microphone (DL-265).

duo2 (DL-71). doc format body|quote|bullet|numbered|codeblock (new; bold, italic, link and headings exist), doc table … (exists), voice start --doc, view format-bar show|hide.

Build, about 5 days. 3 are shared by every option: the new commands, a caret-state report from the page, voice into the document with one-step undo, and checks. 1 for the SwiftUI strip, beside MarkdownReviewBar. 1 to move the table controls out of the page and redo the table's height. Fits the bundle: no new CodeMirror package.
