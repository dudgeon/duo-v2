Spec [P]

Where. The review bar's place, 44 high under the tabs, a rule below, Duo's one button. Shown on every Markdown document: amends DL-237's bar and answers Q-265 differently (today it shows only with marks, comments or Suggest Edits on). View › Hide Document Bar hides it.

Controls. Style ⌄ as a button. Bold, Italic, Link and Table in one bordered group, segments 28 × 24 with hairlines between, the on segment selected. Suggest (the dot) and Review ⌄ at the right, then the mic, 26 round. ⋯'s Strikethrough and Code go into Style ⌄'s foot.

Review ⌄ holds Next and Previous Change, the Markup modes, Show Closed Comments, Accept All and Reject All (and per person), then the counts. Every review command keeps its menu item and chord (⇧⌘E, ⌥⌘M).

Tables. Unchanged (DL-113): the in-document bar, and Format › Table.

duo2 (DL-71). doc format body|quote|bullet|numbered|codeblock, voice start --doc, view doc-bar show|hide; doc review and doc markup unchanged.

Build, about 5 days. 3 shared (as in A). 1 to fold the review bar's controls into one menu and always show it. 1 for the narrow cuts and checking the review flows again. Every document gains 44, where today it gains nothing until it's reviewed.
