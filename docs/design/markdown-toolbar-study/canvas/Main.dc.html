A minimal formatting bar for Markdown documents, with the mic

Geoff: “a UI bar for Markdown controls, like paragraph style, bold, underline, link, insert table, table controls, etc. … relatively minimalist … use it to include the transcription button.” Research: docs/design/markdown-toolbar-study/README.md. Nothing here ships in 0.2.22.

Today, captured (isolated Duo, fixture data, Light)

No bar. Formatting is the Format menu and ⌘B ⌘I ⇧⌘X ⌘K (DL-108, DL-189); Code, headings, Task and tables have no chord. The table bar shows only with the caret in a table (DL-113). The review bar (44) shows only when a document has marks or comments, or Suggest Edits is on (DL-237). Voice reaches chat and the terminal, not documents.

Recommendation

A. It's the only option that keeps the mic in sight on every document (Geoff's point in the voice round: show that transcription is there) without making review chrome permanent. It also puts the table controls in the bar as asked, at the smallest height that still shows everything (32). B crowds at 360 and puts Suggest Edits and Review on documents that never use them. C costs nothing at rest but hides the mic, and its controls sit far from a table near the top.

In every option

Style ⌄ (Body, Heading 1–3, Quote, Bulleted List, Numbered List, Task, Code Block), Bold, Italic, Link, Insert Table, ⋯ (Strikethrough, Code), then the mic. No underline: see Q-345. The mic is chat's look (DL-261, DL-265), dictating a phrase at a time at the caret, with one ⌘Z for a whole dictation (see the dictation board). duo2: doc format body|quote|bullet|numbered|codeblock, voice start --doc.
