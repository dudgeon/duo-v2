DECISION 2 How a window is pinned to a project, and how you can tell A pinned window shows one project. It has no All projects altitude, and it keeps the project through relaunches.
A · A Pin button beside the project's namerecommended
Not pinned: a quiet Pin in text2 after the project's name. Pinned: the glyph fills, it reads Pinned, and All projects leaves the breadcrumb. Click to toggle; also View › Pin Window to Project and duo2 window pin.
B · Pinned only when it opens
Open in New Window makes a pinned window; New Window makes a free one. The mark shows only when pinned, and Window › Unpin frees it. Fewer controls, but you can't pin a window you're already in.
C · Only in the Window menu and the title
Window › Pin to refunds, and the window's title reads "refunds (pinned)". Nothing in the toolbar, so nothing to learn, but nothing tells you why ⌘↑ won't go up.
