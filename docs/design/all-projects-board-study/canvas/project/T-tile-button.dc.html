What it does. It starts a Claude session in the tile's folder, in chat or terminal as Settings says, and opens the project's page on it, as the sidebar's button does inside a project. A folder with no project file starts there too (Claude asks its own trust question), and stays a folder.
Why a row, not a +. It sits inside the tile's frame and reads as a sentence, so you can tell which project it belongs to, and it lines up with the session rows above it. T2's + is quieter, but it's easy to miss, and a + in a name row usually means "add a project".
Keys and verbs. The arrow keys already move focus between tiles (§6.3). With a tile focused, ⌘T starts the session there, and the row shows ⌘T. With no tile focused, ⌘T works as it does today (Home, else ~/Documents) (Q-543). duo2 session new --project checkout-redesign, or --folder ~/repos/site for a plain folder: both exist. The tile's menu gains New Session.
P T1: a 24 pt last row under a hairline (selected), the + in the glyph column, in text2 at 12. Hover: selected fill, text. The tooltip names the project and its folder.
P Tiles in a project's colour or a window's tint are unchanged; the row takes the tile's ground.
