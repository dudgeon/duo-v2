Notes
  • Make a Project does what it does today: writes the starter PROJECT.md and opens it in the Project tab. Undo removes it. [P]
  • Not Now hides the notice for that folder only, remembered by Duo (not written in the folder). The line under the name and the Project tab keep the offer. Undo brings it back. [P]
  • The line under the name, Folder · no project file, matches the map tile (“Has CLAUDE.md · no project file” when it has one), where a project shows its health and next step. [P]
  • Same notice whether or not the folder has a CLAUDE.md. [P]
  • The console’s empty state says “Nothing has run in this folder yet” for a folder, not “project”. [P]
  • Not Now gets a duo2 verb (DL-71), e.g. duo2 project make <folder> --not-now. [P]
