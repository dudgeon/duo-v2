A task as a single line: a box, its title, its status. Used for tasks with no sessions yet and for open tasks at All projects.

**Status:** Designed (DL-100, slice2 `map-folders.html`, `session-rows.html`); the hover + is designed (DL-112, stand-ins `q43-hover.html`; the group style, DL-132 `standins2-handoff/q46-hover`: the `selected` fill, status whole, the + after it); the right-click menu is designed (DL-115, task-menu `task-menu.html`). **In code:** `Model/AppModel+Tasks.swift` `TaskLine`, `TasksFold`, `TaskStatusMenu`, `NewSessionInTaskButton`, `TaskRowHover`; `Model/AppModel+TaskMenu.swift` `TaskMenuItems`.

**Anatomy:** `rowSession` (26): a drawn task box (8 pt rounded square, stroke 1.3, in a 10 box; `TaskBox`) in `text2`, the title in `body`, at All projects the project in `text2`, then the status in `text2` when it's past `open`. Inside a project they sit in a `Tasks · n` fold under the history, indented 18 under the fold; at All projects under an **Open tasks · n** label after Ready for review.

**Hover (DL-112):** the row takes a `selected` fill (`radiusSelection`, inset `selectionInset` and from the fold's indent) and a + replaces its status: a `rowActionSize` (18) square, `rowActionRadius` (4), the + at `rowActionGlyph` (14) in `text2`, no fill of its own, the system tooltip "New Session in Task". A group-style task row shows the same + at its trailing end, where a wait would sit, with no hover fill.

**Behaviour:** click opens the task's note (going to its project first); the + is New Session in Task (`duo2 task session`): a Claude session linked from the note, with `@tasks/<note>.md` typed into its prompt once Claude is ready and not sent (DL-112). Right-click (DL-115, the same on a group-style task row): Open Task Note, New Session in Task, Add Session ▸ — Rename, Mark Complete, Set Status ▸ (open, in progress, waiting, review, done, dropped, the current one ticked) — Copy Link, Reveal in Finder, Move to Project ▸ — Archive Task…, Delete Task…. Archive, Delete and Move ask in a Duo question whether the task's sessions go too (task-menu `task-questions.html`). Rename selects the name in the note; the file follows the new name's slug once typing pauses. Done, dropped and archived tasks leave the lists; an archived task sits in the project's Archived fold with "n sessions" in `text2`, and its menu is Open Task Note — Copy Link, Reveal in Finder — Unarchive Task, Delete Task….

**Open for design (S2-5):** the box, status display, and whether Home's list belongs in the action column.

**Motion (DL-130):** Mark Complete shows the line checked, struck through and in `text2` for `motionRowHold` (5 s); ⌘Z or Mark Open keeps it. Then it fades out (`motionRowOut`) while the lines below close up. Lines are opaque on the pane. With Reduce Motion, it still holds 5 s, then goes at once.
