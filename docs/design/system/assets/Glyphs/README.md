Glyphs are the five session-state glyphs, drawn in a 10 × 10 box and shown at 9 pt. Shape carries the state; colour is secondary.

| File | State | Ink |
|---|---|---|
| `needsYou` | Needs you: filled circle | `needsYou` (#C2410C); `needsYouOnConsole` on the console |
| `readyForReview` | Ready for review: filled diamond | `text` (#1F2328) |
| `working` | Working: ring, stroke 1.5 | `text` |
| `idle` | Idle: dash, stroke 1.6 | `text2` (#5B636D) |
| `resolved` | Resolved: check, stroke 1.6 | `text2` |

On the console, inactive tabs draw them in `consoleText2`.
