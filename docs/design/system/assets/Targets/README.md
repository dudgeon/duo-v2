Targets are rendered PNGs of the approved design screens, at 1440 wide. The HTML originals are in the repo under `docs/design/<handoff>/screens/`; they are the literal build target unless a decision changed them (see Surfaces).

- `overview.png`, `project.png`: All projects and inside a project (build-handoff). Since then:
  - their topic labels became folder columns (DL-92);
  - the session list's state sections became Needs you / Open / history (DL-91);
  - the toolbar field reads `Search all projects ⇧⌘A` (DL-80).
- `flow-zoom-4.png`: The peek and zooming into a project (build-handoff).
- `look.png`: The component sheet (build-handoff): glyphs, labels, rows, pills, tiles, cards and buttons in every state.
- `search-overview.png`, `search-look.png`: The search modal and its component sheet (search-handoff).
- `idle-list.png`, `console-empty-states.png`, `console-tabs.png`, `home-none.png`: Surfaces slice 1 (DB-1, DB-3, DB-4).
