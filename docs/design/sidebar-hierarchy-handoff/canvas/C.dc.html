C · Now, then the rest

Live work leads, whatever it belongs to. A NOW section holds every task with a live session and every live loose session; the rest keeps DL-174's split below it. [P] throughout.

Proposed · 300
What's drawn
1
The director's slot, as in A, above everything.
2
NOW · n: task groups with a live session (open in Duo, working or needing you), with all their sessions; then live loose sessions at the task rows' level, tinted, Keep Running ones first. Order: most urgent, then most recent.
3
TASKS then holds the in-play tasks with nothing live, then Later, then + New task.
4
OTHER SESSIONS loses Open (its sessions are in NOW) and keeps Today, This week and Earlier.
Good
  • Exactly “live over long-range”: what's running is at the top, task or not.
  • Open as a group goes away: NOW says the same thing with fewer folds.
Costs
  • Undoes part of DL-174, which you chose: tasks and loose sessions share a section again (DL-93's mixing, which DL-174 replaced).
  • Rows travel between NOW and TASKS or Today each time a tab opens, closes or parks, so the list moves under the pointer more (DL-130's hold softens it).
  • A task is in NOW because one session is open, though its other sessions may be days old.
Top to bottom
