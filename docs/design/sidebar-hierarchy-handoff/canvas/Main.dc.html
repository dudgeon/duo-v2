Sidebar hierarchy: the director on top, live work over long-range tasks

Your note: “when a project has a duo director and the session is pinned/keep awake, it should appear at the very top of the sessions list; right now it gets buried under all of the tasks … if a project has many tasks, some are long range, it does not make sense for them to always take precedence, especially over live tasks.” Every mark on this canvas is a proposal [P]. Sample data throughout (a checkout project with 16 tasks, the size of your shop project). Comment on any board, or answer the decisions on the right.

What goes wrong
  1. TASKS always comes first, and lists every task. Twelve task lines nobody has touched this week sit above every live session.
  2. The director is just a loose session. Kept running and working, it lands in OTHER SESSIONS › Open, after all the tasks. So do other Keep Running sessions.
  3. A task line with no session never moves. Task groups sort by their most urgent session; lines don't, so long-range work holds its place forever.
  4. Nothing marks the director, or says there are two. A replaced director that's still open looks like any other session.
Rules every option shares [P]
  • The director is the session `.duo/director.json` names as current, by session id. A name starting “director-” proves nothing (DL-200), so a session's name never puts it in the slot.
  • Live means open in Duo (a tab, running or parked), working, or needs you, as Open and NEEDS YOU count today.
  • In play: a task with a live session, or one that ran in the last 3 days, or whose note changed in the last 3 days (a director's Progress line counts). Status isn't used: directors set in-progress, and most people never update it.
  • Later · n: every other task, in a fold at the end of TASKS, folded to start, most recent first. A task leaves Later the moment something happens in it.
  • Order inside TASKS stays: most urgent session (needs you, review, working, idle), then most recent activity. Task lines now sort by their note's last change, among the groups.
  • Nothing new on disk. The order is worked out from sessions and notes; which folds are open is view state, as for the time groups.
The four options

A · Director slot, tasks ranked. The director gets a two-line slot above everything. TASKS folds long-range work into Later. Keep Running sessions stay where they are.

B · Pinned on top. Recommended As A, with every Keep Running session under the director in PINNED. One idea: what you keep running, you keep in view.

C · Now, then the rest. A NOW section above TASKS holds every live task group and live loose session. Bolder: live work leads, whatever it belongs to.

D · The backlog lives on the board. The sidebar shows tasks in play only. The rest is one row that opens the task board.
