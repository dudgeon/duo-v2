Console tabs
A Claude session’s tab starts with its state glyph. A shell’s tab starts with a prompt mark and is named for what it is running, or for the shell when it is waiting.
+ still starts a Claude session. The chevron beside it offers a shell.
Typing claude in a shell turns its tab into a session tab in place. Nothing announces it but the glyph.
