# Acceptance walks

Geoff accepts each big batch of work by walking it in the built app, using the `acceptance-walk` skill (`.claude/skills/acceptance-walk/SKILL.md`). Each walk has a folder here: `features.json` (what to test), `walk.html` (the published page) and `walk.md` (the ledger: page URL, what it covers, status, outcome).

The walk page is responsive: on a phone it shows open questions first, then the cards Geoff can walk on his work Mac as they are (`workMac`), then the rest. The director publishes it (DL-166).

A walk can be deferred: verdicts live in the page's database, so nothing is lost, and the next session picks it up from the ledger.
