## What's new

**Appearance**
- **Duo has a dark appearance.** Settings › General › Appearance offers Match System (the default), Light and Dark, and it changes live with no relaunch. `duo2 settings appearance` sets it too. Duo's own surfaces turn dark: the sidebar, tabs, sheets, terminal, editor and chat. A browser tab follows the appearance. HTML pages, Word documents and decks keep their author's colours, and the app icon doesn't change.

**Tabs**
- **Tabs scroll when many are open.** In the console, the right pane and Home, tabs keep their natural width in a strip that scrolls sideways, with fades at the edges where there's more. The selected tab is always scrolled into view, and a menu at the end (n ⌄) lists every tab.
- **Shells are titled by what's running,** or by their folder when nothing is.
- **Closing a tab selects its real neighbour** to the left, and a restore whose tab is gone selects the first one.

**Sidebar**
- **A clearer order in the project pane:** Pinned, Needs you, Open, Tasks, Other sessions. Keep Running sessions sit at the top, and the director leads them in its own slot. Open sessions that belong to no task sit above tasks.
- **Quiet tasks fold away.** Tasks without recent activity move into a "Later" fold so live work comes first.
- **A single click in the file tree selects** a file; double click or Return opens it. The tree also scrolls to a file you reveal or select.

**GitHub issues**
- **Link an issue to a task** with an `issue:` line in the task note. The task's card shows the issue's live state, and you can Close or Reopen it from Duo.
- **New Issue from a task,** and Push adds "Closes #n" to the pull request for a linked issue. `duo2` has verbs for each.

**Terminal**
- **Shift+Return is a soft newline** in Claude tabs, also on older Claude Code that doesn't ask for the keyboard protocol.
- **⌘⌫ deletes to the start of the line.**

**The director**
- **A new session gets the released director.** The skill is now named `director` (so `/director` reaches it; `duo-director` stays as an alias for now). Duo warns when the installed skill and the app differ, and asks before hiding a project skill of the same name.
- **A director hears its workers whatever the permission mode,** and never relies on bypassing permissions.

**duo2 and installing**
- A project name that matches several projects is reported as ambiguous, with the matches listed, instead of picking one.
- Installing the director skips a CLAUDE.md it can't read or write (a link, read-only or locked file), says why, and carries on.

## Requirements
macOS 26 or later, Apple Silicon, Claude Code installed.

## Install
Open the DMG and drag Duo to Applications. Installed copies update themselves. The `duo2` command is at `Duo.app/Contents/Helpers/duo2`.
