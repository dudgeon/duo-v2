## What's new

**The director**
- **Directors work without Duo open.** Every `duo2 director` verb now runs with Duo closed, and workers start in the background by default.
- **Workers start one way.** A director starts workers only through `duo2 director start`, and they get Remote Control.
- **A logged-out Claude CLI is caught.** If the CLI isn't signed in, starting a worker stops with a clear message instead of leaving a stuck session.
- **No cap on workers.** A director can run as many workers as it needs.

**Word documents**
- **Word documents read like Google Docs.** The viewer defaults to Arial 11, 1.15 line spacing and Google's heading styles. A document's own styles still win, and missing fonts are swapped for close matches.
- **Tracked changes draw right in every view.** Insertions and deletions show correctly in each markup view.

**Chat mode**
- **A Debug button on the chat-fallback bar.** When a session drops back from chat to the terminal, Debug opens a copyable report: which rule fired, what the screen looked like, versions and recent transitions.
- **Chat no longer flips back on its own.** Once a session has fallen back, it stays in the terminal until you switch it.

**duo2**
- `duo2 session chat why [--log]` prints the same report from the command line, and shows the local log of automatic fallbacks.

## Requirements
macOS 26 or later, Apple Silicon, Claude Code installed.

## Install
Open the DMG and drag Duo to Applications. Installed copies update themselves. The `duo2` command is at `Duo.app/Contents/Helpers/duo2`.
