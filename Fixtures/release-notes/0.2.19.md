## What's new

**Forks**
- **`/branch` in a Duo session splits into two live tabs.** The new branch gets its own tab and the original reopens in its tab, so you can work in both.
- **`/fork` opens an attach tab** for the forked session. A fork's tab attaches to Claude's background session for that fork.
- **Forks show as a thread in the sidebar.** The original leads and its forks hang under it; a fork's tab carries a small fork mark. A fork made in Duo opens its thread for you, and closing an attached fork's tab detaches it.
- **Chat send works in an attached fork tab.** Sending from the chat composer into a `/fork` tab now pastes your message instead of failing.

**Trust this folder**
- **A "Trust this folder" notice.** When Claude Code stops a `/fork` with "Workspace not trusted" and a folder above the repository is already trusted, a bar appears under the terminal (or over the chat composer). Trust This Folder… asks first in a Duo sheet that names the folder and the one change, then marks the repository trusted for Claude Code. Fork Again repeats your `/fork`. `duo2 session trust-folder <id>` does the same, and always shows the sheet.

**Projects**
- **Make a Project interviews you.** After writing the starting PROJECT.md, Duo starts a Claude session in the folder that reads it, asks you a few questions one at a time, and fills in the goal, next step, why, done-when and a log line. Every Make a Project button does this, and so does `duo2 project make` (add `--no-interview` to skip it). New Project's "Start a Claude session in it" is now the interview.

**Tasks**
- **Claude knows about Duo tasks.** Sessions in a project are told that tasks exist and how to use them with `duo2`, and new projects' PROJECT.md gets a Tasks section.

**duo2**
- `duo2 task new` has `--no-open` and `--status`.
- `duo2 session trust-folder` and `duo2 session fork-again` are new.

## Known gaps
- Make a Project in a folder Claude Code hasn't trusted yet shows Claude's own trust prompt first, in the interview's terminal. Answer it and the interview carries on.
- Inside a `/fork`, `duo2` reaches your default Duo rather than a differently-configured one.

## Requirements
macOS 26 or later, Apple Silicon, Claude Code installed.

## Install
Open the DMG and drag Duo to Applications. Installed copies update themselves. The `duo2` command is at `Duo.app/Contents/Helpers/duo2`.
