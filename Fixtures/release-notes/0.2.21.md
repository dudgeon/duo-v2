## What's new

- **Review in Markdown** ([video](https://github.com/dudgeon/duo-v2/releases/download/v0.2.21/release-0-2-21.mp4)). Suggest edits and leave comments right in a Markdown file, the way you would in a Word or Google doc. Suggestions and comments show in a margin column beside the text, and Duo keeps them in the file as plain text marks, so any editor can read them. Tag a comment `@claude` and it goes to a session, with the delivery state shown on its card. Convert to Markdown now keeps a Word document's tracked changes and comments as suggestions and threads.
- **Select several sessions and act on them together.** ⇧-click selects a range, ⌘-click toggles one, and selecting never opens or resumes a session. One menu acts on the whole selection, and Delete n Sessions… asks once. A folded fork thread unfolds and selects all its sessions, and deleting a fork's parent now keeps the fork.
- **Lists renumber and indent properly.** Ordered lists renumber after edits, nested lists on their own, and ⌘] ⌘[ Tab ⇧Tab indent or outdent an item by its parent marker's width.
- **New Return chords in chat.** ⌥↩ or a trailing `\↩` adds a line, ⌘↩ sends, and ⌃↩ sends now (Claude Code 2.1.275 or later). In the chat composer, ⌘] indents and ⌘[ outdents, and stepping between your messages moves to ⌥⌘↑ and ⌥⌘↓.
- **The update question shows the release notes.** Every bold lead is listed in a box that scrolls, and `duo2 update` prints the notes.
- **Review shortcuts.** ⇧⌘E turns Suggest Edits on and off, and ⌥⌘M adds a comment.
- **Review fixes.** `duo2` comment and suggestion verbs are thread changes, never suggestions, when Suggest Edits is on, and the margin's foot follows the active card's height.
- **`duo2` document tooling.** `duo2 doc layout` reads a Word file's page, margins, tables and pictures; `duo2 doc screenshot`, `duo2 browser screenshot --full-page` and `duo2 browser scroll` were added, and wide tables scroll in their own box.

## Requirements

macOS 26 or later, Apple Silicon, Claude Code installed.

## Install

Open the DMG and drag Duo to Applications. The `duo2` command is at `Duo.app/Contents/Helpers/duo2`. Installed copies update themselves.
